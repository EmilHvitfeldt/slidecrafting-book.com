# quarto-revealjs skill

A single, router-style skill for building, theming, and presenting [reveal.js](https://revealjs.com) slide decks authored in [Quarto](https://quarto.org/docs/presentations/revealjs/). Distilled from [slidecrafting-book.com](https://slidecrafting-book.com).

`SKILL.md` is a thin index: feature tables that point to focused files in `references/`. The agent skims the index, then loads only the one reference that matches the task.

## Coverage

- **core-** — new deck setup, slide syntax, title slide, backgrounds, footer/logo, overflow
- **theme-** — the 10-minute theme, fonts, colors, sizes, advanced SCSS, variants, syntax highlighting, menu button
- **layout-** — columns, `r-fit-text`, absolute positioning, images, overlay text boxes, `.spread`, paper cards
- **content-** — code highlighting, unexecuted blocks, hand-styled code, asciicast, transparent plot backgrounds, figure sizing
- **animation-** — fragments, custom fragments, auto-animate, transitions
- **present-** — speaker notes, speaker view, chalkboard, PDF export, multiplex, navigation, slide numbers
- **extension-** — editable, codewindow
- **misc-** — hiding slides, includes, editor snippets

The deep-dive skills `quarto-revealjs-fragment` and `auto-animate-elements` remain available standalone; their material is summarized here under `animation-fragments-custom` and `animation-auto-animate`.
